# my-console-app

Dies ist eine einfache Konsolenanwendung, die in .NET erstellt wurde.

## Projektstruktur

- **Program.cs**: Einstiegspunkt der Anwendung mit der `Main`-Methode.
- **my-console-app.csproj**: Projektdatei, die Abhängigkeiten und Einstellungen definiert.
- **README.md**: Dokumentation für das Projekt.

## Verwendung

Um die Anwendung auszuführen, verwenden Sie den Befehl:

```
dotnet run
```
